# Triage 标签

这些 skills 使用五个规范的 triage 角色。本文件把这些角色映射到本仓库工单系统中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库工单中的标签 | 含义 |
| -------------------------- | ------------------ | ---- |
| `needs-triage`             | `needs-triage`     | 维护者需要评估该工单 |
| `needs-info`               | `needs-info`       | 等待报告者补充信息 |
| `ready-for-agent`          | `ready-for-agent`  | 规格完整,可交给 AFK agent |
| `ready-for-human`          | `ready-for-human`  | 需人工实现 |
| `wontfix`                  | `wontfix`          | 不予处理 |

当某个 skill 提到某个角色(例如"打上 AFK-ready 的 triage 标签")时,使用本表中对应的标签字符串。

按你实际使用的词汇修改右侧一列。
